# 🤖 J.A.R.V.I.S. — Real-Time Voice Assistant & Daily Scheduler

> *"Just A Rather Very Intelligent System"* — A low-latency, bidirectional streaming voice assistant inspired by Iron Man's J.A.R.V.I.S., built with Python and the Gemini Live API.

---

## ✨ Features

- ⚡ **Real-Time Bidirectional Audio:** Streams speech back and forth with near-zero latency, functioning like Gemini Live or Google Assistant.
- 🛑 **Live Interruption (Barge-In):** Cut in and speak mid-sentence—J.A.R.V.I.S. instantly stops talking and listens.
- 🗣️ **Natural Spoken Delivery:** Uses native voice generation for fluid human inflections, pacing, and tone.
- 📅 **Personal Scheduler & Friend:** Manages daily agendas, tracks tasks, and engages
